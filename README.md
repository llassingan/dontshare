## 🛠️ Built With

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- Vanilla CSS (Modern aesthetics, glassmorphism, dynamic animations)

## 🚀 Getting Started

If you've stumbled upon this repository and wish to uncover its secrets locally:

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Start the local server:**
   ```bash
   npm run dev
   ```

- **Mysterious Atmosphere:** Designed with dark mode aesthetics and subtle micro-animations.
- **Dynamic Interaction:** Engaging hover effects and responsive UI that feels alive.
- **Fully Responsive:** Seamless experience across all devices.
